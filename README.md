# Healthcare Data Cleaning & Understanding

## Project Overview
This project focuses on exploring, cleaning, and analysing a healthcare dataset containing patient-related information such as age, gender, disease, medication, and dosage.

The objective is to understand healthcare data, identify data quality issues, and perform basic analysis using Microsoft Excel.

## Project Objectives
- Explore and understand the healthcare dataset.
- Identify different data types and column categories.
- Identify missing values and duplicate records.
- Clean and organise the dataset.
- Calculate the total number of patient records.
- Identify the most common diseases.
- Calculate the average patient age.

## Tools Used
- Microsoft Excel
- GitHub

## Project Workflow
1. Healthcare dataset exploration.
2. Data type identification.
3. Missing value identification.
4. Duplicate record identification.
5. Data cleaning.
6. Basic healthcare data analysis.
7. Findings and observations.

## Key Analysis
The following metrics will be analysed:
- Total patient count.
- Most common diseases.
- Average patient age.
- Missing and duplicate records.

## Project Status
Currently in progress.

## Learning Outcomes
Through this project, I aim to develop practical skills in healthcare data handling, data cleaning, Excel-based analysis, and understanding healthcare datasets.
